# Renaming Curb → Nocrave: research notes (QUYT was the first pick; see why it fell)

*11 Sep 2026. Everything below was checked live on the real App Store (web, per storefront), the iTunes Search API, DNS, USPTO and EUIPO. Not legal advice.*

## Why rename at all

- "Curb" cannot be owned in App Store search: `curb` → Curb (taxi, 142K ratings), `curb addiction` → **Curb – Stop Cravings** and **Curb: Drink less** (same category, same name). Even the exact title "Curb: Addiction Recovery" is not in the US top-12 today; it is #1 in India only because India's index is sparse and every install so far is Indian.
- Two same-category apps already named Curb = a permanent Guideline 4.1(c)/5.2.1 exposure and a permanent word-of-mouth leak.
- App is 3 days old, 0 ratings — the rename is free today.

## What Apple's search actually does (learned the hard way)

- The web/phone store shows **12 results per query**, ranked by per-storefront installs, ratings and text match. Exact title match does not guarantee a slot in a crowded storefront.
- **Unknown spellings are auto-corrected** to the nearest real word or brand (qwitt→Twitter, quitlee→Quizlet, tideless→Timeless, sobrly→Soberly, resistr→resistor). This only matters *before* you're indexed; once an app exists with that exact spelling it is the exact match and ranks first for it (that is how QUITTR beats "quitter"). So the only hard rule is: **nobody else may already use the spelling.**
- App Store Connect enforces name uniqueness on the exact string, so "QUYT: …" will be accepted.

### ⚠️ Verdict changed: QUYT is NOT low-risk in India

Identical word, class 9, goods that literally name "Mobile apps" and "Software for mobile phones", registered in the founder's home jurisdiction and still in force. Consequences:
- An Indian TM application for QUYT would be cited against and very likely opposed.
- The registrant could send a cease-and-desist / App Store 5.2.1 complaint. He appears to be a phone-accessories seller, so *actual* use for apps is doubtful (a non-use cancellation is possible after 5 years, i.e. now), but that is a fight, not a launch.
- US/EU remain clear — the problem is India specifically.

**Because of this, the App Store Connect rename was deliberately not performed** (the founder's instruction was to proceed only if the name was low-risk). Nothing in ASC was changed; 1.1.1 is still Waiting for Review under "Curb: Addiction Recovery".

Founder's view after seeing this: the registrant has no app, so the practical risk is low. That is a fair read of *enforcement* probability — but the registration still blocks an Indian TM filing for QUYT until cancelled for non-use (possible: registered 2018, >5 years), and that cancellation is a proceeding, not a form.

## Fifth batch — direct names, suggestive words, dodge-the-urge phrases

- **Direct** ("Quit Addiction" is already an app). Break Addiction: no exact app, only a dead "BREAK THE ADDICTION" mark — but descriptive (unownable), icon truncates to "Break Addict…", and search shows the whole category by definition. Beat Addiction (live "BEAT ADDICTION RECOVERY" class 44), End Addiction (live "Partnership to End Addiction"), Quit Forever / Quit For Good / Just Quit (dozens of quit-smoking titles) all worse.
- **Suggestive single words** (Reins, Brake, U-Turn, Fortitude, Reroute, Rudder, Bearing, Failsafe, Ripcord, Guardrails…): all taken as apps except Failsafe (India class-9 mark), Ripcord (BASF pesticide mark incl. India), Guardrails (three blocker apps use "Guardrail").
- **Dodge-the-urge phrases**: Ride It Out (two apps, one a quit app), Steer Clear (69K-rating app). Clean: **Sit Tight** (US: posture-app noise, IN: noise; USPTO: one live mark in class 3 cosmetics, dead class 9), **Shrug Off** (US: dictionary noise, IN: no results), **Brush Off** (kids-game noise; USPTO first hit dead class 21), Stave Off, Wave Off, Turn Away, Wait It Out, Stay Put, Noped, Nopely.

QITT is the cleanest of the misspelled-"quit" set: no TM anywhere, no app anywhere, domains free, and it is not a near-homophone of any existing brand (QUITTR = "quitter", Kwit = "quit", QITT = "quit" — QITT and Kwit sound alike, but Kwit has no Indian or US registration under that exact spelling in this search; verify before filing).

### Likelihood-of-confusion read (QUYT vs QUITTR)

- For: "quit" is descriptive for a quit app and heavily diluted (227 live US marks); QUITTR's protectable element is the `-TTR` styling. QUYT is one syllable ("quit"), QUITTR is two ("quitter"); 4 letters vs 6; no shared tail. A dozen quit-misspellings already coexist on the store.
- Against: identical goods and audience (class 9/44, same shelf); same underlying meaning.
- Net: **low risk**, clearly lower than KWITR (echoes both QUITTR and Kwit) or CURBR (next to Curb Mobility). Apple 4.1 copycat review looks at name **plus icon/branding**; with Curb's own icon there is nothing to flag.

## Decision (11 Sep 2026)

**Nocrave: Addiction Recovery.** Chosen by the founder after ~450 candidates. Clean on the real App Store (US noise only, India "no results"), no trademark in WIPO's 89 offices, 7-character icon label. 1.1.1 was approved by Apple before the rename, so the rename ships on **1.1.2** (new build: display name "Nocrave", in-app strings, website, legal pages). ASC steps for the founder: create version 1.1.2 → App Information → Name → "Nocrave: Addiction Recovery" → attach the 1.1.2 build → paste the rebrand note from `docs/store/review-notes-ios.txt` → submit.
