SkillsA practical set exclusive animations.dev skills you can use to help you build better animations with AI. It consists of 15 skills designed to do one specific task well.Why use it?The biggest value of the course is building a foundation of knowledge that informs your decisions, an instinct. When you go through the course diligently, you shouldn’t technically need these skills you, because you know the rules and principles.When you have that knowledge, that instict, you also know exactly what to ask for.Instead of spending time on manual labor of building the thing, you can delegate that to the AI and the result will likely be pretty good since you asked for the right thing, and thanks to the skills, it follows the right rules as well.You can then focus on the details that matter, because the base has been already built for you.And since you’ve taken the course, you are among the most leveraged people to use these skills. Use them as an amplifier of your knowledge, because you know what great looks like.InstallationRun this command in your terminal and follow the instructions:
```
npx @animationsdev/install --token=...
```
You’ll choose whether to install into the current project or globally, and which tools to install the skills for. You’ll also have the ability to rename any of the skills to your liking.UsageEach skill is designed to do one task well. Most of them are invoked automatically, but a few are deliberately manual, marked with invoke by name below. The reason is you rarely want a whole-codebase audit as a side effect of asking a question for example.animateUse this to create your animations. It contains all the course knowledge like the easing blueprint, so it will make the right design as well as code decisions for you.>/animate Can you animate this dialog? It’s currently static.css-animationsUse it to build CSS-only animations. Transitions vs @keyframes, all about transforms, 3D, clip-path reveals, recipes for hover reveals, toast stacks, staggered text, marquees and spinners. Also fixes hover states flicker.>/css-animations Reveal these list items one after another on load.motion-reactMostly useful for debugging motion-react specific issues.>/motion-react My exit animation never plays when this modal closes.motion-briefUse it to decide an animation before you build it. It asks one question at a time, each with a recommended answer. You get back a written brief: the properties that animate on enter and exit, the transform-origin, the easing curve and duration, what happens when it’s interrupted mid-flight, and how to handle reduced motion. Or a verdict that this shouldn’t animate at all.>/motion-brief Write a motion brief for this command palette before we build it.pick-ui-libraryHave your agent pick the right UI library for the task based on libraries I use and trust. It reads your package.json before recommending anything, and recommends one thing.>/pick-ui-library I need a toast component, can you recommend a library for that?find-animation-opportunitiesinvoke by nameSearch your UI for places that would genuinely benefit from motion, while also telling you what not to animate.>/find-animation-opportunities Find animation opportunities in the checkout flow. It's used a few times per session by each customer, factor this in.prototypeinvoke by nameBuilds multiple different versions of an animation or UI element so you can go through them using a switcher. The version you select will be saved via query params so you can share it with your teammates.>/prototype Can you prototype a multi-step sign up form? Give me 4 different versions.review-animationsinvoke by nameReviews the motion in a diff against ten non-negotiable standards, and rejects or approves the changes. It catches ease-in on UI, transitions past 300ms, the wrong transform-origin, and animation on an action someone performs a hundred times a day.>/review-animations Review the motion in my current branch.improve-animationsinvoke by nameUse your most capable model to audit animations in your project and hand the execution to cheaper models.>/improve-animations Survey this app and write plans I can hand off.animation-performanceHelps debug performance issues with animations.>/animation-performance This drawer is smooth on my laptop and stutters on my phone, can you help?animation-accessibilityHelps make your animations more accessible. Covers prefers-reduced-motion, useReducedMotion and MotionConfig, plus autoplaying video, GIFs and infinite loops.>/animation-accessibility Make this multi-step component accessible.animation-vocabularyHelps you get better animations from an AI by telling it exactly what you want by using the right words.>/animation-vocabulary What’s it called when one shape turns into another one?gesture-uiUse it for anything the user drags, swipes, or holds. Think of drawers, draggable cards, swipe-to-dismiss, and so on.>/gesture-ui Make this bottom sheet draggable with swipe to dismiss.scroll-animationsScroll reveals and scroll-driven animation for marketing pages. It reveals once instead of re-triggering, prefers CSS scroll-driven animations over scroll listeners, and so on.>/scroll-animations Add scroll reveals to this landing page, tastefully.debug-animationUse it when an animation feels off but you can’t say why. Made specifically for debugging, so it can look for and tell you exactly what’s wrong. Based on the course knowledge, like all the other skills.>/debug-animation This modal transition feels cheap and I can’t tell why.FAQHow are these different from your free skills on GitHub?The public ones are trained on my public work, the articles on emilkowal.ski, my tweets, and my open source libraries. They’re free and they’re good, and for those that haven’t taken the course (not you), they’re a great start.The skills on this page are trained on the course: the easing blueprint, the duration ranges, the exercises, and the reasoning behind every rule, most of which I have never published anywhere. That matters most when your agent faces a decision I never wrote a blog post about. The public skills only have the conclusions I happened to publish. The skills here explain where conclusions came from, so the agent has more flexible knowledge and can adapt to scenarios that are not covered in the skill itself, because it knows the why.But you also get more skills here. animate, motion-brief, animation-performance, motion-react, and more, are all skills available exclusively here.Do these cost extra?No. Every skill on this page is included in the course, and so is every future update to them.How do these relate to emil.md?They’re built for different jobs. The skills on this page are narrow and animation-specific. Each one does a single task, and none of them know anything outside of motion.emil.md is the opposite: broad and personal. It’s everything I know about design engineering, not just animations, closer to a dump of my brain. Most people run both: these for the motion decisions, emil.md for the taste calls around product work.Is emil.md the same as the skills in AI for UI?No. emil.md is deliberately opinionated. It’s everything I personally do and think is good, which is why it reads like my brain. The aiforui.dev skills are more general, and each one is scoped to a specific job rather than to how I’d do it.Worth saying: in AI for UI the skills are just one part of the course, not the core.How do I get updates?Run the install command again. The skill content is fetched at install time, so a re-run always gives you the current version.
